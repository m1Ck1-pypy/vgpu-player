## Как проверить

```bash
# окно без файла: Play открывает диалог, работают O, меню и перетаскивание
cargo run -q -p player-app
cargo run -q -p player-app -- assets/test/sync_test.mp4

# примеры библиотеки (just сам копирует DLL в target/debug/examples)
just example-minimal
just example-embed

# портативная папка — запускать двойным кликом из Проводника
dist/vgpu-player/player-app.exe

# установщики (per-user, без UAC)
dist/vgpu-player-0.1.0-setup.exe    # Inno Setup 7
dist/vgpu-player-0.1.0.msi          # WiX v3
```

Запускать **без прав администратора**, иначе Windows не отдаст файл при
drag-and-drop (UIPI).

Ожидаемо:

- панель: play/pause, динамик, ползунок громкости, кнопка fullscreen, «⋯»;
  кнопки «Открыть» и постоянного процента нет;
- после конца файла — `replay` в панели и круглая «Повторить» поверх кадра;
- `O`/`Ctrl+O`, пункт «Открыть…» и перетаскивание открывают один файл;
  выбранный файл показывает превью первого кадра и играет по `Space`;
- файл без видео — нота и «Аудио файл»; надписи «готов к воспроизведению» нет;
- панель лежит поверх кадра, полупрозрачна, видео не перевёрстывается;
- при перетаскивании — «Отпустите файл, чтобы открыть»; каталоги и
  несуществующие пути игнорируются; битый файл даёт экран ошибки с «Повторить»;
- меню «⋯»: «Открыть…», «Информация о файле» (только при открытом файле),
  «Скрыть/Показать оверлей статистики» с галочкой, «О программе»,
  «Автоскрытие панели» с галочкой; закрывается по `Esc`, выбору пункта и клику
  по кадру вне списка;
- «Информация о файле» — имя, путь, размер, контейнер, длительность, видео
  (кодек, разрешение, fps), звук (кодек, каналы, частота);
- «О программе» — `VGPU Player 0.1.0` и версии `libavutil`/`libavformat`/
  `libavcodec`;
- время в панели и инфо-панели — `чч:мм:сс`, ширина не прыгает;
- `Esc` сначала закрывает меню/панели, затем выходит из fullscreen; клик по
  кадру — пауза/продолжение, клик по меню/кнопкам воспроизведение не трогает;
- колесо — громкость ±1 %, снимает mute; процент над ползунком едет за курсором,
  после колеса появляется плашка справа снизу и исчезает через ~1,5 с;
- Play без файла открывает диалог; выбранный файл запускается повторным Play;
- в `dist/` и установленной версии: release без консоли, в Проводнике/заголовке/
  панели задач — оранжевая киноплёнка и «VGPU Player»;
- Inno ставит в `%LOCALAPPDATA%\Programs\vgpu-player`, MSI — в
  `%LOCALAPPDATA%\vgpu-player`; оба создают ярлык и удаляются без остатка;
- `minimal` выглядит как `player-app`; `embed_in_app` — кадр и своя панель
  («Открыть…», play/pause, «−5 с», «+5 с», время, имя файла), `Space`/`←`/`→`/`O`.

## Что сделано (что менять осторожно)

- **Открытие файла:** `VideoPlayer::open_dialog` на `App::prompt_for_paths`
  (без `rfd`), `open_dropped`, `Shortcut::OpenFile` (`O`/`Ctrl+O`), drop через
  `ExternalPaths` + `on_drop`. Плашка и проверка прав администратора удалены по
  просьбе владельца — UIPI описан в §11 (п. 14).
- **Иконки:** 9 монохромных SVG в `player-gpui/src/icons.rs` (`open` удалена,
  добавлены `fullscreen`/`fullscreen-exit`), подписи — только `aria_label`.
- **Меню «⋯»** (`app.rs`): кнопка + список над панелью, пункты-переключатели,
  «Информация о файле» (`Player::media_info()`), «О программе»
  (`player_core::FfmpegVersions`). Пока меню/инфо открыты, автоскрытие стоит.
  Видимость оверлея — `VideoPlayer::stats_visible` (не сбрасывается при смене
  файла).
- **Панель поверх кадра:** `controls_panel()` — `.absolute()` внутри области
  кадра, `rgba(0x11_11_11_cc)`; меню поднято на `CONTROLS_HEIGHT = 60`.
- **Превью и аудио-заглушка:** `player_core::preview_frame` в `open`; для файла
  без видео — `Icon::Note` и «Аудио файл».
- **Мышь и `Esc`:** клик по кадру — `toggle_playback` (после закрытия оверлеев
  клик только закрывает их), колесо — ±1 % с автоснятием mute, `Esc` закрывает
  панели, затем fullscreen.
- **Fullscreen:** иконки `Fullscreen`/`FullscreenExit`, `icon_button` получает
  `&mut Window`; `VideoPlayer::fullscreen` синхронизируется из
  `Window::is_fullscreen()` в `render` (бэкенд асинхронен — §11, п. 10).
- **Громкость:** `volume_hover` и `volume_hint_left` (подсказка едет за курсором,
  ширина 44 px), `volume_notice` в `PlayerWindow` на 1,5 с
  (`VOLUME_NOTICE_DURATION`), правый край слайдера даёт ровно 100 %.
- **Клик по панели не ставит паузу:** `controls_panel` гасит `on_mouse_down`
  через `stop_propagation()` — ловушка GPUI описана в §11 (п. 6).
- **Play без файла:** `play_action(Idle) = OpenFile` в `controls.rs`, `aria_label`
  «Открыть видео».
- **Имя «VGPU Player»:** `WINDOW_TITLE`, «О программе», Inno (`AppName`,
  `AppPublisher`, ярлыки), MSI (`Product Name`, `Manufacturer`, ярлык).
  Технические имена остались `vgpu-player`.
- **Иконка exe:** `assets/app-icon.ico` ← `assets/icon.png`, `build.rs` +
  `embed-resource` + `app.rc` (`1 ICON`, числовой ID — §15.3).
- **Установщики:** `installer/vgpu-player.iss` (per-user, Inno 7) и
  `installer/vgpu-player.wxs` + `AppFiles.wxs` (WiX v3, per-user). Проверены
  тихой установкой, запуском и удалением; `just installers` пересобирает всё.
- **Примеры и README:** `embed_in_app.rs`, `minimal.rs`, README с таблицей API;
  код README в doc-тестах, реэкспорт `gpui_platform`.
- **Пул BGRA (этап 8):** `Player::recycle_frame`, `next_frame_with_buffer`,
  `convert_into`; предел `QUEUED_FRAMES + 2`, очистка на `Open` — §11 (п. 5), §13.

## Известные ограничения

- Плейлиста и сохранения позиции нет — решение владельца; открывается один файл.
- Drag-and-drop не работает в процессе с правами администратора (UIPI). Плашки
  и проверки прав нет; запускать без повышения, включая терминал/редактор.
- Кнопки «Открыть» в панели нет; имя файла — только в «Информации о файле».
- Превью — только первый кадр: тёмное начало даст чёрное превью.
- Панель закрывает нижние ≈52 px кадра; высота зашита в `CONTROLS_HEIGHT = 60`.
- Модификаторы в горячих клавишах не различаются: `Ctrl+O` и `O` — одно действие.
- У кнопок нет подсказок при наведении (только `aria_label`); подсказка с
  процентом есть только у ползунка и обновляется по движению мыши.
- Меню управляется только мышью: стрелки/`Tab` не ходят, галочка — текстовый «✓».
- Клик по панели управления меню не закрывает (чтобы не терять его при работе
  со слайдером).
- `VideoPlayer::fullscreen` — копия состояния окна; потребитель `controls_view`
  обязан синхронизировать её в `render` (как демо-окно).
- Настройки (`stats_visible`, `auto_hide_enabled`) — только в памяти процесса.
- Release без консоли (`windows_subsystem = "windows"`): для логов запускать
  debug-сборку.
- `dist/vgpu-player/` — артефакт: после `cargo clean` или обновления FFmpeg
  пересобрать (`just portable`). WiX лежит в `.tools/wix` (не в git) — на новой
  машине скачать заново.
- Inno Setup 7.1.1 печатает `Non-commercial use only`; MSI этого ограничения не
  несёт.
- Примеры требуют DLL в `target/debug/examples/` (это делает `just`).
- Замеры CPU/RSS сняты в CLI; стоимость копии в GPU-текстуру видна только в окне
  (§13.2).
- Open-вопросы прошлых этапов: троттлинг стрелок, сведение двух
  демультиплексоров, возврат `Loading` при сетевом открытии, ошибки
  `gpui_windows` при закрытии окна (известный шум), YUV-текстура.

## Drag-and-drop: диагностика

Работает в обычном процессе; лог успеха:

```text
DEBUG player_gpui::app: файлы над окном
DEBUG player_gpui::app: файлы отпущены над окном count=1
 INFO player_gpui::video_player: файл открыт в UI path=...
```

Если drop не работает:

1. Перезапустить без повышения прав (проверить и терминал/редактор): `Win+R` →
   `powershell` → `cargo run -p player-app`.
2. Подсказки нет — события не доходят: тащить из Проводника (архиваторы и
   браузеры могут не отдавать `CF_HDROP`), прислать лог.
3. Подсказка есть, отпускание молчит — разбирать GPUI: лог и версия Windows.
4. «Файлы отпущены», файл не играет — смотреть ошибку открытия в логе.

Известный шум: FFmpeg печатает `Could not update timestamps for skipped
samples` на Opus-файлах (pre-skip), на воспроизведение не влияет.
