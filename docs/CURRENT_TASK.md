## Задача

Аудиофайл вместо статичной заглушки (нота + «Аудио файл») должен показывать
спектроанализатор: столбики в такт звуку, логарифмическая шкала, компенсация
наклона спектра. Решения владельца: только аудиофайлы (видео не трогаем),
без новых зависимостей, без подписи «Аудио файл» (метаданные есть в меню),
цвета — как у иконки приложения.

## Как устроено

- **`crates/player-core/src/spectrum.rs`** (новый, внутренности `pub(crate)`):
  - `SpectrumTap<S>` — обёртка `rodio::Source`: сводит каналы в моно и кладёт
    сэмплы в кольцо. Ставится между `SamplesBuffer` и `CountingSource`, то есть
    видит ровно то, что rodio забрал на вывод, — картинка не опережает звук
    на очередь `QUEUED_CHUNKS`.
  - `SpectrumRing` — кольцо на `AtomicU32` + номер записи `AtomicU64`:
    один писатель (поток вывода), один читатель (ядро), без `Mutex`. При
    переполнении читатель пропускает старое — визуализатору нужен свежий звук.
  - `SpectrumAnalyzer` — окно 2048, окно Hann, свой радикс-2 FFT, 48
    логарифмических полос 40 Гц…16 кГц, tilt +4.5 дБ/окт от 1 кГц, диапазон
    −80…0 дБFS, сглаживание attack 0.6 / release 0.15 на кадр. Уровень полосы —
    максимум магнитуды по бинам (среднее «просаживало» широкие верхние полосы).
  - `SpectrumBars` — `[f32; 48]`, событие не аллоцирует; `ZERO` для сбросов.
- **`event.rs`**: `Event::Spectrum(SpectrumBars)`.
- **`player.rs`**: анализатор создаётся только для файла без видео; чтение
  кольца и событие раз в 33 мс; сброс и нули на `Open`/`Seek`; нули на `Ended`;
  на паузе событий нет — столбики замирают. `AudioSink` держит `Arc<SpectrumRing>`;
  `chunk_to_source` принимает необязательный тап.
- **`video_player.rs`**: поле `spectrum`, разбор события, `spectrum()`; сброс
  при открытии/остановке.
- **`video_view.rs`**: для файла без видео — 48 столбиков, прижатых к нижнему
  краю и растянутых по ширине окна (90 % высоты, отступы 24 px), цвет
  интерполируется от оранжевого `0xef8a2e` к жёлтому `0xffd93d`
  (цвета иконки), минимальная высота 3.5 % — ровное основание в тишине.
  Заглушка с нотой и текстом удалена, иконка `Note` убрана.
- **`lib.rs`**: `player-gpui` реэкспортирует `SpectrumBars` и `SPECTRUM_BARS`.

Громкость и `mute` на уровни не влияют: анализ снимается до регулятора rodio.
Видеофайлы спектр не считают и событий не шлют.

## Известные ограничения

- На паузе столбики замирают на последних значениях (не гаснут).
- Slope/tilt — константы `TILT_DB_PER_OCTAVE`/`TILT_REFERENCE_HZ`, не настройка
  и не пункт меню.
- Первые полосы на самых низких частотах могут пересекаться по бинам: при
  окне 2048 (~23 Гц) разрешение там грубее шага логарифмической шкалы.
- Для видео с дорожкой звука анализ не считается: оверлея поверх кадра нет.
- `SpectrumTap` делает один `AtomicU32`-store на моно-сэмпл в потоке вывода.
