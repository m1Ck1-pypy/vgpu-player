# VGPU Player

<img src="assets/icon.png" width="96" alt="VGPU Player">

Видеоплеер локальных файлов на Rust и [GPUI](https://github.com/longbridge/gpui-fast)
для Windows. Учебный проект: цель — понять каждую строку и научиться Rust, а не
сделать конкурирующий плеер.

Версия 0.4.0. Этапы 0–13 приняты: звук и видео, A/V-синхронизация по
аудио-часам, управление, надёжность, пул BGRA-буферов, полировка интерфейса,
библиотека `player-gpui`, установщики, ассоциации файлов, автовоспроизведение,
сохранение настроек, спектроанализатор для аудиофайлов.

## Возможности

- воспроизведение локальных видео- и аудиофайлов через Symphonia / FFmpeg;
- аудиофайл показывает спектроанализатор: 48 логарифмических столбиков
  с компенсацией наклона (без опережения звука);
- пауза, перемотка, громкость, mute, полноэкранный режим;
- тёмное оформление в палитре иконки приложения: оранжевые кнопки и
  заполнение слайдеров, жёлтые переключатели и `LIVE`;
- клик по кадру — пауза/продолжение; двойной клик — полноэкранный режим;
  колесо мыши — громкость шагами по 1 % с плашкой-индикатором;
  громкость — по значку динамика: выдвижная панель с mute и ползунком;
  минимальный размер окна — 560×315, чтобы таймлайн не сжимался;
- горячие клавиши: `Space`, `←`/`→`, `F`, `O`, `Esc`;
- открытие файла диалогом, из меню и перетаскиванием в окно; файл сразу
  играет (пункт «Запускать сразу» в меню «⋯» отключает это);
- превью первого кадра, «Информация о файле», «О программе»;
- настройки (автовоспроизведение, оверлей, автоскрытие, громкость) сохраняются
  в `%APPDATA%\vgpu-player\settings.cfg`;
- оверлей статистики синхронизации, автоскрытие панели вместе с курсором мыши;
- библиотека `player-gpui` для встраивания плеера в чужое GPUI-приложение;
- открытие видео двойным кликом и через «Открыть с помощью»: ассоциации ставит
  установщик, для портативной папки — `register-associations.cmd`;
- HTTP-заголовки источника (`Referer`, `User-Agent`) для ссылок вроде RuTube
  `play_stream`, которым мало одного URL; они уходят на все запросы,
  включая HLS-сегменты;
- YouTube VOD по обычной ссылке (`youtube.com/watch?v=…`, `youtu.be/…`,
  `/shorts/…`) — анонимно, через HLS-манифест; YouTube live, плейлисты,
  вход и age-restricted пока не поддерживаются;
- портативная сборка и установщики: Inno Setup и MSI (WiX).

## Структура

| Путь                 | Что внутри                                                                 |
| -------------------- | -------------------------------------------------------------------------- |
| `crates/player-core` | движок без GPUI: демультиплексирование, декодирование, часы, синхронизация |
| `crates/player-gpui` | библиотека UI: `VideoPlayer`, `video_view`, `controls_view`, `run_app`     |
| `crates/player-app`  | демонстрационное приложение                                                |
| `crates/player-cli`  | консольный запуск ядра и замеры                                            |

| `assets/`            | иконка; тестовые медиафайлы генерируются локально                          |

## Требования

- Rust 1.98+ (требование `gpui-fast`);
- Windows 10/11 x64;
- FFmpeg 9 с `libdav1d` — dev-библиотеки для сборки и DLL для запуска;
- `just` — для готовых команд `portable`, `installers` и примеров
  (необязательно, все команды можно выполнить вручную);
- звуковое устройство по умолчанию (без него плеер покажет экран ошибки).

Для сборки библиотеки на Linux нужны системные зависимости GPUI (wayland,
xkbcommon, fontconfig, vulkan, alsa) — они перечислены в CI
(`.github/workflows/ci.yml`).

## Сборка и запуск

FFmpeg ставится через vcpkg один раз на машине:

```bash
git clone https://github.com/m1Ck1-pypy/vgpu-player.git
cd vgpu-player
git clone --depth 1 https://github.com/microsoft/vcpkg.git .tools/vcpkg
.tools/vcpkg/bootstrap-vcpkg.bat -disableMetrics
.tools/vcpkg/vcpkg install "ffmpeg[avcodec,avdevice,avfilter,avformat,swresample,swscale,dav1d]" --triplet x64-windows --recurse
cp .tools/vcpkg/installed/x64-windows/bin/*.dll target/debug/
cp .tools/vcpkg/installed/x64-windows/bin/*.dll target/debug/deps/
```

Сборка и запуск:

```bash
cargo build -p player-app
cargo run -p player-app -- path/to/video.mp4
cargo run -p player-app -- file:///C:/video/movie.mp4
```

Release-бинарник называется `vgpu.exe`. После установки Inno/MSI каталог
приложения добавляется в пользовательский `PATH`, поэтому в новой консоли
можно запускать:

```bat
vgpu "https://…"
vgpu
```

Источник и параметры можно ставить в любом порядке; громкость задаётся
процентами `0…100` и действует только на этот запуск:

```bat
vgpu "https://…" --volume 40
vgpu --volume 0
```

Ссылки, которым нужны HTTP-заголовки, получают их флагами `--referrer`
(алиас `--referer`) и `--user-agent`. Заголовки действуют на все запросы
источника — probe, `Range`-блоки и HLS-плейлисты с сегментами. Пример для
RuTube (`play_stream`):

```bat
vgpu "<media-url>" --referrer https://rutube.ru/ --user-agent "Mozilla/5.0"
```

`vgpu --help` (`-h`, `-H`, `/?`) печатает справку: источники, `--volume`,
`--referrer`/`--user-agent`, цитирование ссылок и управление в окне.
В release-сборке приглашение
возвращается сразу, а текст появляется после него; без консоли (двойной
клик) справка открывается окном сообщения.

Аргумент разбирается как источник: путь, `file:` или `https://`. Без
аргумента открывается пустое окно плеера. Прямые `http(s)`-ссылки на
MP4/MKV/WebM/MP3 и HLS (`.m3u8`, VOD и live) играют. YouTube VOD
(`watch?v=`, `youtu.be`, `/shorts/`) открывается анонимно через HLS;
YouTube live, плейлисты и вход пока не поддерживаются. Окно во время открытия
показывает «Загрузка…» и не замирает. Формы `file:///D:/…`, `file://D:/…`,
`file:/D:/…` и `file:D:/…` равнозначны; `file://server/share/…` — UNC,
`file://localhost/…` — локальный путь.

### Ссылки с пробелами, скобками и «умными» кавычками

Ссылку или путь с такими символами в консоли нужно передать одним
аргументом. `Source` понимает `%20`, поэтому ссылку можно вставлять как есть,
но оболочка разбирает строку до запуска плеера:

- PowerShell считает `(` и `“…”` своим синтаксисом — без кавычек `vgpu`
  не запускается, а в консоли появляется `Имя "…" не распознано как имя
командлета`. Это не ошибка плеера, а разбор командной строки;
- `cmd` делит команды по `&`, а не по скобкам;
- bash разбирает `(`, `)` и `&`.

Поэтому берите аргумент в ASCII-кавычки:

```powershell
vgpu 'file:///D:/yt-downloader/Sān-Z,%20HOYO-MiX%20-%20“FURYON”%20(ft.%20Alaina%20Cross).mp3'
```

```bat
vgpu "file:///D:/video/my%20file.mp3"
vgpu "https://example.com/a.mp4?token=1&x=2"
```

```bash
vgpu 'file:///D:/video/my file.mp3'
```

В PowerShell вместо кавычек можно поставить `--%`: остаток строки уйдёт
в аргументы без разбора.

Если сборка идёт из Git Bash и `PATH` подхватывает `/usr/bin/link.exe`, добавьте
`RUSTFLAGS="-Clinker=rust-lld"` (см. `docs/SPEC.md`, раздел 12.4).

Тестовые медиафайлы в git не входят. Команды генерации —
`assets/test/README.md`; для быстрой проверки подойдёт любой локальный файл.

## Управление

| Действие            | Как                                                   |
| ------------------- | ----------------------------------------------------- |
| Пауза / продолжить  | `Space`, кнопка play/pause или клик по кадру          |
| Выбрать видео       | кнопка Play, пока файл не открыт                      |
| Перемотка ±5 с      | `←` / `→`                                             |
| Полноэкранный режим | `F` или кнопка в панели; `Esc` выходит из него        |
| Открыть файл        | `O` / `Ctrl+O`, меню «⋯» → «Открыть…», перетаскивание |
| Громкость           | ползунок или колесо мыши (±1 %)                       |
| Автовоспроизведение | меню «⋯» → «Запускать сразу» (по умолчанию включено)  |
| Оверлей статистики  | меню «⋯» → «Показать оверлей статистики»              |
| Закрыть меню/панели | `Esc` или клик по кадру                               |

Процент громкости не занимает место в панели постоянно: он появляется
подсказкой над ползунком при наведении и плашкой в правом нижнем углу после
шага колесом (исчезает через ~1,5 с).

## Настройки

Настройки из меню «⋯» и громкость сохраняются между запусками в
`%APPDATA%\vgpu-player\settings.cfg`:

```text
# VGPU Player settings
autoplay = true
stats_visible = false
auto_hide = true
volume = 0.8
```

| Ключ            | Что задаёт                                          | Умолчание |
| --------------- | --------------------------------------------------- | --------- |
| `autoplay`      | начинать воспроизведение сразу после открытия файла | `true`    |
| `stats_visible` | оверлей статистики синхронизации                    | `false`   |
| `auto_hide`     | скрывать панель управления после бездействия        | `true`    |
| `volume`        | громкость `0…1`                                     | `1.0`     |

Громкость из `--volume` перекрывает сохранённую только на время запуска и
обратно в файл не пишется; изменение громкости в окне (ползунок или колесо)
сохраняется как обычно.

Файл можно править вручную: неизвестные ключи и мусорные строки игнорируются,
неверные значения заменяются умолчаниями. Удалите файл, чтобы сбросить всё к
умолчаниям. Портативная и установленная версии пишут в один и тот же файл.

## Портативная сборка и установщики

```bash
just portable        # release-exe + dist/vgpu-player/ (exe + DLL)
just installer-inno  # dist/vgpu-player-0.4.0-setup.exe
just installer-msi   # dist/vgpu-player-0.4.0.msi
just installers      # portable + оба установщика
```

`dist/` — артефакт сборки, в git не попадает. Inno Setup 7.1.1 на машине
разработчика печатает `Non-commercial use only`; для коммерческого
распространения нужна лицензия Inno Setup или NSIS (в проекте NSIS-скрипта
нет, примечание — `docs/SPEC.md` §15.2). MSI собирается WiX Toolset v3:
скачайте `wix314-binaries.zip` с
<https://github.com/wixtoolset/wix3/releases> и распакуйте в `.tools/wix`.
Для Inno нужен установленный Inno Setup 7 (`ISCC.exe`).

Оба установщика добавляют каталог установки в пользовательский `PATH`
(`HKCU\Environment`, без прав администратора). После установки откройте
**новую** консоль и проверьте:

```bat
where vgpu
vgpu "https://…"
```

Уже открытые консоли сохраняют старое окружение. URL с `&` передавайте в
кавычках: в `cmd` этот символ разделяет команды. Скобки и «умные» кавычки
в имени файла тоже требуют кавычек — см. раздел о запуске из консоли выше.
Удаление установщика убирает из `PATH` только свою запись.

### Ассоциации файлов

Оба установщика регистрируют плеер для видео и аудио (HKCU, без прав
администратора). Чтобы заработал двойной клик:

1. ПКМ по файлу → «Открыть с помощью» → «Выбрать другое приложение…»;
2. выберите VGPU Player и галочку «Всегда использовать это приложение».

Умолчание установщик не перехватывает: с Windows 8 выбор пользователя хранится
в `UserChoice` и защищён хэшем, поэтому прямая запись в `.mp4` всё равно была
бы проигнорирована. Удаление снимает только свои записи. Для портативной
папки то же делает `dist/vgpu-player/register-associations.cmd` (снять —
`register-associations.cmd remove`). Добавить или убрать портативную папку
в пользовательском `PATH` можно вручную:
`register-associations.cmd path` и `register-associations.cmd path remove`.

Второй клик по видео при уже запущенном плеере запускает второй экземпляр:
передачи пути в существующее окно пока нет.

## Использование как библиотека

`player-gpui` даёт готовый `VideoPlayer`, виджет `video_view` и необязательную
панель `controls_view`. Подключение, API и примеры — в
[`crates/player-gpui/README.md`](crates/player-gpui/README.md).

```bash
just example-minimal   # готовое окно через run_app
just example-embed     # своё окно, video_view и свои кнопки
```
